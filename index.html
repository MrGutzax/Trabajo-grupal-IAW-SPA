Ringua: Red IoT de Monitorización y Control Inteligente

Simulación integral de una infraestructura IoT para supervisar el nivel de agua, temperatura, humedad y caudal en tiempo real, automatizando actuadores mediante scripts en Python.

Conocer el proyecto Ver catálogo IoT Abrir panel de control

¿En qué consiste Ringua?

Ringua es un proyecto desarrollado en 2º de Administración de Sistemas Informáticos en Red (ASIR) por Dennise, Rashed, Fiorella, Ángel y Gustavo. Combina el diseño de redes locales e inalámbricas en Cisco Packet Tracer con la programación de microcontroladores y nodos IoT en Python, centralizando las lecturas de sensores y el estado de los actuadores en un panel web accesible desde la red local.

Red y Topología

1. Simulación en Packet Tracer

Diseño de una red segmentada con Home Gateway, router principal, punto de acceso inalámbrico y servidor central IoT con direccionamiento IPv4 estático y DHCP.

2. Scripts en Python

Lógica programada en Python dentro de los nodos y placas controladoras para leer sensores periódicamente y activar electroválvulas, bombas o alarmas según umbrales.

3. Dashboard Web

Interfaz de supervisión centralizada para consultar las métricas clave del sistema (nivel de agua, temperatura, humedad y caudal) y el registro de eventos recientes.
